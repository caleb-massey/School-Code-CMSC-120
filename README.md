# CMSC 120 — Stripe

The starter for the first Java classes of CMSC 120, Fall 2026.

- `src/Stripe.java` — the program. Yours to edit.
- `src/Check.java` — `Check.is(...)`, which is Pyret's `is` for Java. Keep it beside your file and do not edit it.
- `src/Version.java` — prints which Java you are running.

## In IntelliJ IDEA

Welcome screen → **Get from VCS** → paste this repository's URL → **Clone**.
IDEA puts the folder under `IdeaProjects` in your user directory; that is
where the files live. Then open `src/Stripe.java` and press the green Run
arrow beside `main`.

## On OneCompiler

The same files, saved there. <https://onecompiler.com/java/4544z33u6> holds
`Stripe.java` with `Check.java` beside it. <https://onecompiler.com/java/4544z24zr>
holds `Version.java` on its own, because OneCompiler will not run two kinds of
`main` in one program.
